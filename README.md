# Парк Монрепо

Адаптивный учебный сайт о музее-заповеднике «Парк Монрепо» (г. Выборг).

Лабораторная работа №1 по дисциплине «Вёрстка и прототипирование».

## Технологии

- HTML5 (семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (Flexbox, Grid, CSS-переменные, медиазапросы, mobile-first)
- JavaScript для мобильного меню
- Логотип нарисован средствами CSS

## Структура

```
├── index.html      Главная: о парке (текст + 5 фото)
├── history.html    История усадьбы
├── sights.html     Достопримечательности
├── visitors.html   Информация для посетителей
├── works.html      Задания курса и курсовая
├── partials/       Общие header и footer
├── css/style.css   Общие стили
├── js/layout.js    Подключение header и footer, мобильное меню
└── images/         Фотографии
```

## Как открыть

Сайт нужно открывать через локальный сервер или GitHub Pages. Если открыть `index.html` двойным щелчком, header и footer не подгрузятся: браузер не даёт странице читать соседние файлы.
